# game_observaciya

Простая HTML5-игра (вид сверху) про врача обсервационного отделения.

## Запуск

Откройте `index.html` в браузере.

## Управление

- `← ↑ ↓ →` — перемещение врача по коридору.
- `Пробел` — применить текущий предмет к ближайшему пациенту у двери бокса.

## Механики

- У пациентов периодически возникает одно из состояний: агрессия, голодовка, жажда, потребность в туалете.
- В коридоре появляются предметы: шприц, еда, вода, ключ.
- Если не помочь вовремя, пациент теряется по соответствующей причине.
- Ведётся статистика времени и потерь по причинам.
