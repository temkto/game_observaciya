# game_observaciya

Простая HTML5-игра (вид сверху) про врача обсервационного отделения психиатрического стационара.

## Запуск

Откройте `index.html` в браузере (двойной клик по файлу или через любой локальный сервер).

## Управление

- `← ↑ ↓ →` — перемещение врача по коридору.
- `Пробел` — помочь ближайшему пациенту у двери (если в инвентаре нужный предмет).
- `P` или кнопка `Старт/Пауза` — пауза/продолжение смены.
- `Новая смена` — полный перезапуск.

## Базовые механики

- Пациенты периодически переходят в состояние: агрессия, голодовка, жажда, потребность в туалете.
- В коридоре появляются предметы: шприц, еда, вода, ключ.
- Если не успеть помочь вовремя — пациент теряется по соответствующей причине.
- В HUD ведётся статистика потерь по причинам.
